# 업무 워크벤치 (안드로이드 앱)

할일·캘린더·회의록을 한 곳에서 관리하는 **개인용 업무 앱**입니다.
서버도, 회원가입도 필요 없습니다. **모든 데이터는 내 휴대폰 안에만** 저장됩니다.

- 할일을 말하듯 적으면 날짜·시간·장소를 AI가 뽑아 줍니다. (예: "다음주 금요일 오후 2시 3층 회의실에서 킥오프")
- 회의를 녹음하면 **화면이 꺼져도 계속 녹음**되고, 글로 받아 적어 회의록(요약·결정사항·액션아이템)으로 정리합니다.
- 마감일 **알림**이 정확한 시각에 울립니다. (폰을 재부팅해도 유지)
- 캘린더에 한국 공휴일이 표시됩니다.

## 설치 방법 (휴대폰에서)

1. 이 페이지 오른쪽의 **Releases**(릴리스)로 들어가 가장 위의 **`workhub-vX.X.X.apk`** 를 내려받습니다.
2. 내려받은 파일을 누르면 "출처를 알 수 없는 앱 설치" 허용을 물어봅니다. 지금 쓰는 브라우저(또는 파일 앱)에 대해 **허용**하고 설치합니다.
3. "Play 프로텍트가 앱을 검사하려 합니다 / 알려지지 않은 앱" 경고가 뜨면 **상세 → 설치하기** 를 누릅니다.
   (Google Play에 올리지 않고 직접 배포하는 앱이라 나오는 안내이며, 앱 자체에 문제가 있다는 뜻이 아닙니다.)
4. 업데이트는 새 파일을 같은 방법으로 설치하면 **기존 데이터가 유지된 채** 덮어씁니다.

필요 사양: 안드로이드 7.0 이상. (알림이 정확한 시각에 울리는 기능은 13 이상에서 자동 허용됩니다.)

## 처음 한 번만: AI 키(무료) 넣기

음성 받아쓰기·회의록 정리·할일 자동 인식은 Google Gemini를 씁니다. 각자 **본인의 무료 키**를 넣어야 합니다.

1. 휴대폰 브라우저에서 <https://aistudio.google.com/apikey> 에 구글 계정으로 로그인합니다.
2. **API 키 만들기**를 누르고 나온 `AIza...` 로 시작하는 키를 복사합니다.
3. 앱을 처음 열면 나오는 안내 창에 붙여넣고, 안내 문구를 읽고 동의에 체크한 뒤 **시작하기**를 누릅니다.
   (나중에 ⚙ → 설정에서도 바꿀 수 있습니다.)

> **개인정보 안내** — 녹음한 음성과 입력한 메모는 **내 키로 Google Gemini 서버에 전송**되어 처리됩니다.
> 회사 보안 규정상 회의 내용을 외부에 보낼 수 없다면 음성·AI 기능은 사용하지 마세요.
> (AI 없이도 할일·캘린더·직접 적는 메모는 그대로 쓸 수 있습니다.)
> 무료 키는 하루 사용량 제한이 있습니다. 앱의 ⚙ → *Gemini 사용량*에서 확인할 수 있고, 긴 회의를 녹음하면 한도를 많이 씁니다.

## 업데이트

앱을 열 때마다 새 버전이 있는지 확인하고, 있으면 위쪽에 알림 배너가 나옵니다. **업데이트** 버튼을 누르면 내려받은 뒤 설치 화면이 뜨고, 거기서 **설치**를 누르면 끝입니다. (기존 데이터는 그대로 유지됩니다.)
처음 한 번은 "이 출처의 앱 설치 허용" 화면이 뜰 수 있습니다. 허용을 켜고 돌아와 업데이트를 다시 누르세요.
안드로이드 보안 규칙상 사용자의 확인 없이 몰래 설치할 수는 없습니다.

## 여러 기기에서 쓰기 (구글 드라이브 동기화)

⚙ → 설정 → **구글 계정 연결**을 누르면, 같은 구글 계정으로 연결한 기기(폰·태블릿)끼리 할일·회의록·프로젝트·용어 사전이 자동으로 맞춰집니다.
데이터는 내 구글 드라이브의 **앱 전용 숨김 폴더**에만 저장되며 다른 곳으로 전송되지 않습니다.
직무 설명과 알림·녹음 설정도 함께 맞춰집니다. **API 키는 기본적으로 동기화되지 않으니** 기기마다 넣거나, 설정의 "이 키를 구글 드라이브로 다른 기기와 동기화" 스위치를 켜세요. (켜면 키가 내 드라이브의 앱 전용 폴더에 저장되며, 구글 계정이 탈취되면 키도 노출될 수 있습니다. 끄면 드라이브의 키는 지워지고 각 기기의 키는 남습니다.)
(배포하는 사람이 먼저 [구글 클라우드 설정](docs/구글-드라이브-설정.md)을 한 번 해 두어야 합니다.)

**참석자 입력**: 회의록 작성 화면에 참석자 칸이 처음부터 있습니다(쉼표로 구분, 선택). 적어 두면 AI 정리 때 그 이름을 정확한 표기로 쓰고 음성 인식으로 잘못 적힌 비슷한 이름을 바로잡으며, 글에서 더 찾은 참석자는 뒤에 덧붙입니다. 미리보기에서 고칠 수 있습니다.

**회의록 검색**: 회의록 탭의 "저장된 기록" 위 검색창에 입력하면 즉시 걸러집니다. 제목·요약·프로젝트·참석자·안건·논의내용·결정사항·액션아이템·직접 메모를 찾고, 여러 단어는 모두 들어 있는 기록만 보여 줍니다. 띄어쓰기와 대소문자 차이는 무시하며, 용어 사전에 등록한 틀린 표기와 올바른 표기를 함께 찾습니다. 일치한 글자는 강조되고 카드 아래에 어느 항목에서 찾았는지 한 줄로 나옵니다. "음성 원문까지 검색"을 켜면 음성 변환 원문도 찾고(기본은 꺼짐), 프로젝트로 걸러 볼 수 있습니다. 검색은 폰 안에서만 이루어져 외부로 전송되지 않습니다.

**홈 화면 위젯**: 홈 화면의 빈 곳을 길게 눌러 **위젯**을 열고 "업무 워크벤치"에서 두 가지를 놓을 수 있습니다.
- **할일 목록**: 지연 → 오늘 → 가까운 순으로 모든 할일을 보여 줍니다. 지연·오늘·3일 이내 개수가 위에 표시됩니다.
- **캘린더**: 월 달력에 할일이 있는 날에 점이 찍히고, 날짜를 누르면 그 아래에 그날의 일정이 보입니다. 위쪽 ‹ › 로 달을 넘기고, 달 제목을 누르면 오늘로 돌아옵니다.
위젯은 앱이 마지막으로 열렸을 때까지의 내용을 보여 줍니다. 다른 기기에서 바꾼 내용은 이 폰에서 앱을 열어 동기화한 뒤에 위젯에 나타납니다. 위젯을 눌러도 앱이 열립니다.

**저장공간 확인**: 설정의 구글 드라이브 동기화 영역에 내 구글 계정 저장공간 사용률(막대)과 이 앱이 쓰는 양이 표시됩니다. 사용률이 80%를 넘으면 배너와 알림으로 용량 정리를 안내합니다. (구글 저장공간은 드라이브·Gmail·구글 포토를 합친 값입니다.)

**새로고침**: 화면 맨 위에서 아래로 쓸어내리면 구글 드라이브와 동기화하고 목록을 새로 불러옵니다. (녹음 중이거나 팝업이 열려 있을 때는 동작하지 않습니다.) 또 앱을 다른 화면으로 넘기는 순간 아직 못 올린 변경을 바로 올립니다.

## 알림이 안 올 때 (삼성 갤럭시 등)

알림 시각은 ⚙ → 설정 → 마감일 알림에서 고릅니다. 시간이 정해진 일정은 정각·5분·10분·15분·30분·1시간·2시간·3시간·하루 전 중에서, 날짜만 있는 할일은 마감일 몇 시에 알릴지 고를 수 있습니다. (구글 드라이브 동기화를 켜면 다른 기기에도 같이 적용됩니다.)

휴대폰의 절전 기능이 앱을 잠재우면 알림이 늦어질 수 있습니다.

1. 휴대폰 **설정 → 애플리케이션 → 업무 워크벤치 → 배터리 → 제한 없음**(또는 "최적화하지 않음")으로 바꿉니다.
2. 앱의 ⚙ → 설정 → **테스트 알림**을 눌러 10초 뒤 알림이 오는지 확인합니다.
3. 설정 → 알림 → 업무 워크벤치 알림이 켜져 있는지 확인합니다.

## 백업

데이터는 이 휴대폰에만 있어서, **앱을 삭제하거나 폰을 바꾸면 사라집니다.**
⚙ → 설정 → **백업 파일 저장**으로 파일을 만들어 드라이브나 카카오톡 "나에게"로 보관하고, 새 폰에서 **백업 불러오기**로 복원하세요.
(API 키는 백업에 포함되지 않습니다.)

**백업 불러오기**: 불러올 때 "합치기"(이 기기의 데이터는 그대로 두고 백업의 항목만 더함, 같은 파일을 다시 불러와도 중복 없음)와 "대체"(전부 바꿈) 중에서 고를 수 있습니다.

## 개발자용

```bash
npm ci
bash tests/run.sh                 # 화면·로직 테스트 (Docker 필요, Gemini는 모의 응답)
npx cap sync android              # www/ 를 안드로이드 프로젝트로 복사
cd android && ./gradlew assembleDebug
```

- 화면은 `www/`, 서버판 원본은 `tools/index.server.html`, 변환 스크립트는 `tools/patch_index.py` 입니다.
  `www/index.html`은 변환 결과이므로 직접 고치지 말고 `tools/ui_block.js`·`patch_index.py`를 수정한 뒤 `python3 tools/patch_index.py` 로 다시 만듭니다.
- 네이티브 코드: `android/app/src/main/java/kr/workhub/app/` (녹음 서비스·플러그인).
- 배포: `git tag v0.1.0 && git push --tags` → GitHub Actions가 서명된 APK를 Releases에 올립니다.
  저장소 Secrets에 `WH_KEYSTORE_B64`(키스토어 파일의 base64), `WH_KS_PASS`, `WH_KEY_ALIAS`, `WH_KEY_PASS` 가 필요합니다.
  **서명 키를 잃어버리면 기존 사용자는 업데이트를 덮어 설치할 수 없으니 반드시 따로 보관하세요.**
