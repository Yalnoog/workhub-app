설정

Gemini API 키

키는 Google AI Studio에서 무료로 만들 수 있습니다. 기본적으로 이 기기에만 저장되며, Google에 AI 요청을 보낼 때만 사용됩니다.

내 직무 설명 (선택)

회의록을 정리할 때 AI가 용어를 더 정확히 이해하도록 돕습니다. 구글 드라이브 동기화를 켜면 다른 기기에도 같이 적용됩니다.

마감일 알림

구글 드라이브 동기화

같은 구글 계정으로 연결한 기기끼리 할일·회의록·프로젝트·용어 사전과 직무 설명·알림 설정이 맞춰집니다. 데이터는 내 드라이브의 앱 전용 숨김 폴더에만 저장되고 다른 곳에는 전송되지 않습니다. API 키는 기본적으로 동기화되지 않으며, 위 "API 키 동기화" 스위치를 켠 경우에만 올라갑니다.

백업

데이터는 이 기기에만 있습니다. 기기를 바꾸거나 앱을 지우기 전에 백업 파일을 저장해 두세요. (API 키는 백업에 포함되지 않습니다)

앱 정보

업무 워크벤치에 오신 것을 환영합니다

할일·캘린더·회의록을 한 곳에서 관리합니다. 모든 데이터는 이 휴대폰에만 저장됩니다.

1. Gemini API 키

음성 받아쓰기, 회의록 정리, 할일 자동 분류에 필요합니다. Google AI Studio에서 무료로 만들 수 있습니다. 키 없이도 할일·캘린더·직접 쓰는 메모는 쓸 수 있고, 나중에 설정에서 넣어도 됩니다.

2. 내 직무 (선택)

용어 사전

'틀린 표기'를 적으면 음성 변환·AI 정리 결과에서 자동으로 '올바른 표기'로 바뀝니다. '틀린 표기'를 비우면 교정은 안 하고, 음성 인식과 AI가 그 용어를 정확히 쓰도록 힌트로만 사용됩니다.
