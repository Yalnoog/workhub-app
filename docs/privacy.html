개인정보처리방침

업무 워크벤치 (패키지 kr.workhub.app) · 시행일 2026-10-16

1. 개발자는 사용자의 데이터를 수집하지 않습니다

이 앱에는 개발자가 운영하는 서버가 없습니다. 할일·회의록·프로젝트·용어 사전·설정은 사용자의 휴대폰 안에만 저장되며, 개발자는 이를 수집·열람·저장하지 않습니다. 광고, 사용 통계 수집, 분석 도구는 사용하지 않습니다.

2. 사용자의 요청으로 외부 서비스에 전송되는 정보

  • Google Gemini API: 사용자가 AI 기능(음성 받아쓰기, 회의록 정리, 할일 자동 인식·분류)을 쓸 때, 해당 기능에 필요한 녹음 음성과 입력한 메모·할일 내용이 사용자가 직접 입력한 본인의 API 키로 Google에 전송되어 처리됩니다. 처리 결과는 Google의 약관과 개인정보처리방침에 따릅니다. API 키는 휴대폰에만 저장되며 개발자에게 전달되지 않습니다.
  • Google Drive 동기화(선택): 사용자가 구글 계정을 연결하면 할일·회의록·프로젝트·용어 사전이 사용자 본인의 Google Drive 앱 전용 숨김 폴더(appDataFolder)에 저장되어 기기 간에 맞춰집니다. 요청하는 권한은 drive.appdata 하나이며, 사용자의 다른 드라이브 파일에는 접근할 수 없고 개발자도 이 데이터에 접근할 수 없습니다. 직무 설명과 알림·녹음 설정도 함께 저장됩니다. API 키는 기본적으로 동기화되지 않으며, 사용자가 설정에서 "API 키 동기화"를 직접 켠 경우에만 같은 폴더에 저장됩니다(끄면 삭제).
  • 업데이트 확인: 앱을 열 때 GitHub의 공개 릴리스 정보(최신 버전 번호)를 조회합니다. 사용자 데이터는 전송되지 않습니다.

3. 앱이 사용하는 권한

  • 마이크: 회의 녹음 (화면이 꺼져도 녹음되도록 알림이 표시되는 포그라운드 서비스 사용)
  • 알림 / 정확한 알람: 마감일 알림
  • 설치 요청: 앱 안에서 새 버전을 설치할 때만 사용

4. 보관과 삭제

데이터는 앱을 삭제하거나, 앱의 설정에서 "모든 데이터 삭제"를 누르면 이 휴대폰에서 지워집니다. 구글 드라이브에 올라간 동기화 데이터는 구글 계정의 드라이브 설정(앱 관리 → 숨겨진 앱 데이터 삭제)에서 직접 삭제할 수 있고, 앱의 "연결 해제"로 동기화를 끌 수 있습니다.
