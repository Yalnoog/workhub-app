# 구글 드라이브 동기화 설정 (배포하는 사람이 딱 한 번)

앱이 동료의 구글 계정으로 "앱 전용 숨김 폴더"에 접근하려면, 배포하는 사람이 구글 클라우드에 앱을 한 번 등록해야 합니다.
**동료는 아무 설정도 하지 않고** 앱에서 [설정 → 구글 계정 연결]만 누르면 됩니다. 비용은 없습니다.

요청하는 권한은 `drive.appdata` 하나뿐입니다. 이 권한으로는 사용자의 다른 드라이브 파일을 볼 수 없고,
구글이 "민감하지 않은 권한"으로 분류해서 별도의 구글 앱 심사 없이 쓸 수 있습니다.

## 1. 프로젝트 만들기
1. <https://console.cloud.google.com> 에 로그인합니다.
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `workhub` → 만들기.

## 2. Google Drive API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**.
2. `Google Drive API` 검색 → **사용**.

## 3. 동의 화면 설정 (Google Auth Platform)
1. **API 및 서비스 → OAuth 동의 화면**(또는 *Google Auth Platform*) → 시작하기.
2. 앱 이름 `업무 워크벤치`, 사용자 지원 이메일은 본인 이메일.
3. 대상(Audience)은 **외부(External)**.
4. **데이터 액세스(Data Access) → 범위 추가**에서 `.../auth/drive.appdata` 를 추가합니다.
5. **대상(Audience) → 앱 게시(Publish app) → 프로덕션으로 푸시**.
   - 이걸 안 하면 "테스트" 상태라 등록한 테스트 사용자(최대 100명)만 로그인할 수 있고 7일마다 연결이 풀립니다.
   - 민감하지 않은 권한만 쓰므로 게시해도 구글의 별도 심사는 없습니다.

## 4. 안드로이드 클라이언트 만들기
**API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**

| 항목 | 값 |
|---|---|
| 애플리케이션 유형 | **Android** |
| 이름 | `workhub-android` |
| 패키지 이름 | `kr.workhub.app` |
| SHA-1 인증서 디지털 지문 | `0E:DA:22:D0:3E:97:80:1D:84:EF:FD:78:5B:B1:4F:56:B4:0B:22:9B` |

(SHA-1은 배포용 서명 키의 지문입니다. 서명 키를 새로 만들면 이 값도 바꿔서 다시 등록해야 합니다.)

## 5. 확인
새 버전 APK를 설치하고 **⚙ → 설정 → 구글 드라이브 동기화 → 구글 계정 연결**을 누릅니다.
구글 동의 화면에서 허용하면 "구글 드라이브와 동기화했습니다"가 뜹니다.
같은 계정으로 다른 기기에서도 연결하면 두 기기의 할일·회의록이 합쳐집니다.

문제가 있으면 설정 화면의 오류 문구를 보세요.
- "구글 로그인 설정이 아직 완료되지 않았습니다": 4번(패키지 이름·SHA-1)이 틀렸거나 아직 반영되지 않았습니다. 등록 후 몇 분~수 시간 걸릴 수 있습니다.
- "구글 드라이브 API 설정이 완료되지 않았습니다": 2번(Drive API 사용)을 확인하세요.
