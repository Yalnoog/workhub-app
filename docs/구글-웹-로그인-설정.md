# 웹 버전 구글 로그인 설정 (배포하는 사람이 한 번)

PC 브라우저에서 쓰는 웹 버전(https://yalnoog.github.io/workhub-app/app/)이 구글 드라이브와 동기화하려면,
구글 클라우드에 **웹 애플리케이션용 OAuth 클라이언트**를 하나 더 만들어야 합니다. (안드로이드용과는 별개입니다.)
같은 프로젝트(workhub)에서 만드세요. 이미 해 둔 Drive API 사용 설정, 동의 화면, 게시 상태가 그대로 적용됩니다.

## 만들기
**Google 인증 플랫폼 → 클라이언트 → 클라이언트 만들기**

| 항목 | 입력값 |
|---|---|
| 애플리케이션 유형 | **웹 애플리케이션** |
| 이름 | `workhub-web` |
| 승인된 JavaScript 원본 | `https://yalnoog.github.io` |
| 승인된 리디렉션 URI | 비워 둡니다 |

- 승인된 JavaScript 원본에는 경로(`/workhub-app/...`)나 마지막 `/`를 붙이지 마세요. `https://yalnoog.github.io` 만 입력합니다.
- 만들면 **클라이언트 ID**(`...apps.googleusercontent.com`)가 나옵니다. 이 ID만 알려 주시면 됩니다.
  **클라이언트 보안 비밀번호(Client secret)는 필요 없고, 어디에도 공유하지 마세요.**
- 반영에 몇 분~수 시간이 걸릴 수 있습니다.
